## 작품 개요
음성 인식과 로드셀 측정을 활용하여 조미료를 정량 토출하는 스마트 디스펜서입니다.

## 주요 기능
- 음성 명령 인식
- 솔레노이드 기반 조미료 토출
- 로드셀 기반 무게 측정
- GUI 상태 표시

## 주요 파일
- `demo8.py` : 조미료 디스펜서의 주요 제어 코드
